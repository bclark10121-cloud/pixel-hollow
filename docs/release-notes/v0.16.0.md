# Pixel Hollow v0.16.0

The standards catch-up. No new places or treasures. The game now has the same menus, saves, settings and tester tools as the other games on The Game Shelf, plus an app icon of its own.

## Five minute test

1. Install the APK over v0.15.0. The app icon is new: an open pixel treasure chest on a grassy hill at night. On Android 13 and newer, themed icons show the chest alone.
2. Open the game. The title card shows the icon, the name, one line of controls for what you used last, then Continue (slot 1), Play and Settings, and Version 0.16.0 at the bottom. Your v0.15.0 save is in slot 1.
3. Tap Play. Five slots show. Slot 1 holds your keeper, the treasure count and when you last played. Pick Slot 2. A new game starts with the character builder. Tap Done.
4. While playing, only the treasure counter, the Menu button and the touch controls show. Tap Menu. A row of buttons opens across the top: Resume, Settings, How to play, Journal, Map, Village, Character, Photo mode, Album, Title. The Menu button now reads Close. Tap Close.
5. Open Menu, then Settings. Music, Sound, Frame rate and Rumble come first. Music steps Off, Low, Medium, High, Full. Change something, close the app, open it again. The change stayed. There is no Save button.
6. Press the Home button on your phone, then come back. The Menu row is open and the game is paused.
7. Title, then Play. Press Delete on Slot 2. It reads Press again. Press it again. Slot 2 is empty.
8. Settings, Tester tools, then the code. Try Go to Snowy Peaks and Collect 10 treasures. A DEBUG tag shows at the top while the tools are unlocked.

## New in this version

- Its own app icon, on the phone, the browser tab, the title card and the game page. The old Helena Hollow lantern is gone from this game.
- Five save slots, up from three. Continue opens the slot you played last. Play opens the slot list. Delete asks for a second press. Your old slots keep their saves.
- One Menu button at the top right opens a row of every option across the top. It reads Close while the row is open. Esc, P, View, Menu and the Android back button open and close it. The Journal and Map buttons moved into the row, so the screen stays clear while you play. J, M, Y and X still open them straight away.
- The shared Settings menu: Music and Sound in five levels, Full screen in a browser, a Frame rate number, Rumble, then this game's own settings, then Text size (Normal, Large, Larger), Reduce motion, Reset settings and an About line. Every change saves at once. Your old settings carry over.
- How to play: every key, Xbox button and touch control, with the one you use marked. Settings, Controls opens it too.
- The game pauses with the Menu open when you switch apps or tabs and when your controller disconnects.
- Hints follow what you used last: keys, an Xbox controller or touch. Xbox button names are the default.
- Reset settings, Delete, Restore a backup and Remove a photo each ask for a second press. No pop-up boxes.
- A loading screen while the browser version loads.
- Tester tools behind a code, in test builds only: jump to every area and signpost, switch tools and options, collect treasures, reset or load a test save, game speed, a readout and Copy bug report.
- A privacy page: the game collects nothing and the APK asks for no internet.
- Test helpers now work only when a test opens the page with ?test.
- On a phone held upright the Menu row uses smaller buttons, so it stays in the top half of the screen.
- The source moved to a private repo. The public repo keeps the game page, the builds, the release notes and the backlog.

## Shared kit

Built with kit 1.9.1, the same plain HTML pieces as By Lantern's Glow v0.16.0.

## Install

Version 0.16.0 installs over 0.15.0 and keeps your saves. It installs next to the old Helena Hollow app and does not replace it.

## Full test checklist

1. The title card shows the new icon, the controls line, Continue, Play, Settings and Version 0.16.0. Quit shows only in the Android app.
2. Five slots. An empty slot starts a new game. Delete needs two presses and the game moves to another used slot or slot 1.
3. The Menu row: the order above, Close while open, Esc, View, Menu and Back open and close it.
4. Settings: the standard order and names, five sound levels, Frame rate, Rumble only on Android or with a controller, Text size Larger fits on a phone, Reset settings needs two presses.
5. Switch away and back: the game is paused with the Menu open. Turn a controller off while playing: the Menu opens with a line about the controller.
6. Hints: touch, keys and an Xbox controller each change the controls line on the title card.
7. Tester tools: the code unlocks them with touch, a keyboard and an Xbox controller alone. Copy bug report pastes into a chat.
8. Old saves: a v0.15.0 save is in slot 1 with its finds.
