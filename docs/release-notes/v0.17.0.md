# Pixel Hollow v0.17.0

A new Lantern Hill start screen and a storybook talk box, the same as By Lantern's Glow. Part of one start screen and one talk box for every game.

## Five minute test

1. Install the APK over v0.16.0. Your saves stay.
2. Open the game. The start screen is a pixel-art night: stars, a crescent moon, hills, a lantern on the near hill with a treasure chest beside it and fireflies. Continue, Play and Settings sit below, with Version 0.17.0 at the bottom.
3. Continue and walk up to Old Tom. Press A. A parchment box opens a third of the way down the screen with his name on a red ribbon. The words write themselves out with soft voice blips.
4. Press A once to finish the page. When it reads Press A to close, press again. The box closes and stays closed. Press A again to hear him again.
5. Open Menu, Settings. Under Pixel Hollow, turn Voice blips off and talk again. The text still writes out, now silent.

## New in this version

- The shared start screen (standard G5.21): a pixel Lantern Hill with a chest under the lamp, the title, one controls line, Continue (only with a save), Play, Settings and Quit in the app. The old parchment card is gone.
- The talk box (standard G5.20): parchment, the speaker on a red ribbon, text that writes itself out, long talks in pages, Press A for more or Press A to close, voice blips with a Settings switch. Reduce motion shows each page at once and holds the start screen still.

## Shared kit

Built with kit 1.9.1. The start screen and talk box for plain HTML games live in the game file, copied from By Lantern's Glow.

## Install

Version 0.17.0 installs over 0.16.0 and keeps your saves.

## Full test checklist

1. The start screen on a phone held upright, a phone held sideways and a desktop. Buttons stay readable.
2. Talk box: ribbon names on neighbors, no ribbon on signs, pages turn with A, the closing press never reopens the talk.
3. Voice blips on and off. Reduce motion on.

## Tested and not tested

Tested in headless Chrome on the cloud test machine: a talk box and start screen suite (t36), the standards suite (t35), the menu fit suite at 12 screen sizes (t22) and the quick check with the pretend Xbox controller. The signed APK was checked for its signature, the tester gate and no internet permission. Screenshots were checked by eye.

Not tested: a real phone, the Retroid or a real Xbox controller.
