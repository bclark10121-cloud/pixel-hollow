Helena Hollow is now two games. This one is Pixel Hollow, with the pixel view.

**New in this version**
- A new name, Pixel Hollow, on the title card, the app and the photos.
- The pixel view only. Settings no longer has a Graphics choice.
- Its own Android app. It installs next to the old Helena Hollow app and does not replace it. Both keep their own saves.
- In the browser, your Helena Hollow save comes along the first time you open Pixel Hollow.
- Backup codes (`WV1:`) from Helena Hollow work here too. Copy a code in the old app, then import it in Settings.
- The View button on an Xbox controller opens the Menu, like the Menu button.

**Test checklist**
- [ ] The title card reads Pixel Hollow and v0.15.0.
- [ ] Settings has no Graphics choice. The game always shows the pixel view.
- [ ] Install the APK. It shows up as Pixel Hollow, next to Helena Hollow if you have it.
- [ ] Open the browser version where you played Helena Hollow before. Continue picks up your save.
- [ ] With only an Xbox controller: A starts, Menu and View open the Menu, B goes back, the left stick walks.
- [ ] Copy a backup code in Helena Hollow and import it here. Your finds come over.

**Good to know**
- Tested in headless Chrome on a computer, not on a phone or with a real controller.
- Built with the shared kit 1.5.0 (G10.4).
